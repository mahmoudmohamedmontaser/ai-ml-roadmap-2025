# 🤖 AI & ML Engineer Roadmap 2025-2026

An interactive, production-grade web application and comprehensive roadmap for aspiring AI and Machine Learning Engineers. Features 5 detailed learning phases, 19+ core skills, 5 architecture portfolio projects, interactive interview simulator, ATS resume builder, and local-storage progress tracker.

## 🌟 Features

- **📚 Complete 19-Skill Encyclopedia:** Full technical breakdowns, concepts, goals, and ranked learning resources (Arabic + Global hyperlinks).
- **🛠️ 5 Architectural Portfolio Projects:** Complete with problem statements, pipeline architecture diagrams, step-by-step implementations, and starter code.
- **🎯 Interactive Interview Simulator:** Technical multiple-choice assessment for AI/ML engineering interviews with instant feedback.
- **💼 ATS Resume Builder & Keywords:** Quantified bullet point guidelines and essential 2025/2026 ATS keyword list.
- **⏳ Timeline & Finish Date Calculator:** Calculates estimated completion dates dynamically based on daily study hours.
- **✅ LocalStorage Progress Tracker & Data Export:** Saves completed skills automatically to browser storage with JSON backup export.
- **🚀 Ready for Vercel Deployment:** Zero build setup needed — single-page production web app.

## 📑 Structure & Roadmap Phases

1. **Phase 1: Software CS & Python Architecture** (OOP, Asyncio, Pydantic v2, Pytest, FastAPI, Git, Linux, SQL)
2. **Phase 2: Applied Math & Classic Machine Learning** (Linear Algebra, Calculus, Statistics, Polars/Pandas, XGBoost, Optuna)
3. **Phase 3: Deep Learning & PyTorch Architecture** (PyTorch Tensors, Autograd, Custom Training Loops, Transformers, Hugging Face)
4. **Phase 4: Generative AI, LLMs & AI Agents** (Structured Outputs, Qdrant Vector DB, Advanced RAG, QLoRA Fine-Tuning, LangGraph)
5. **Phase 5: MLOps, LLMOps & Production Infrastructure** (vLLM Serving Engine, Ollama, Docker, Kubernetes, MLflow, Ragas)
